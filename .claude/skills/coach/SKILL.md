# /coach — правки playbook и эксперимента

Работает и интерактивно, и через `claude -p`. **Вопросов не задавать**: чего не хватает — в раздел
«Нужно от Полины» описания PR (или сводки). **Никогда не мержить.**

## 1. Ветка

- `node scripts/now.mjs` → `previousIsoWeek` (неделя последнего разбора). Ветка: `coach/<previousIsoWeek>`.
- `git status` — рабочее дерево должно быть чистым. Если нет — не трогать чужие изменения: напечатать
  «есть незакоммиченные изменения: …» в сводке и закончить, ничего не меняя.
- `git switch main` (или текущая основная ветка), затем `git switch -c coach/<week>`. Ветка уже есть —
  `git switch coach/<week>` и продолжить в ней.
- Нет `analytics/<previousIsoWeek>.md` — записать в «Нужно от Полины» «разбора за неделю нет, /analyst-weekly
  не отработал» и работать по последнему имеющемуся разбору.

## 2. Тренер

Агент `coach` — по своей инструкции: обновить `playbook.md` и `experiments.md`, вернуть сводку.
`brief.md` не менять ни при каких условиях.

## 3. Коммит, push, PR

```
git add playbook.md experiments.md
git commit -m "coach: <week> — playbook и эксперимент"
```

- `git remote` пустой — не пушить; напечатать сводку тренера и «ветка coach/<week> оставлена локально,
  смержи сама».
- remote есть —
  ```
  git push -u origin coach/<week>
  gh pr create --base main --head coach/<week> --title "coach: <week>" --body "<сводка тренера>"
  ```
  Тело PR — сводка тренера целиком, включая «Предложения к brief.md» и «Нужно от Полины».
  `gh` не работает — напечатать сводку и ошибку.
- После — `git switch main`, чтобы ежедневные скиллы коммитили в основную ветку.

Не мержить, не включать auto-merge, не пушить в main.
