# /analyst-weekly — разбор недели

Работает и интерактивно, и через `claude -p`. **Вопросов не задавать**: чего не хватает — в раздел
«Нужно от Полины» итогового файла. Цифры считает агент `analyst` (медианы, посты < 48 ч не оцениваем).

## 1. Какая неделя

- `node scripts/now.mjs` → `previousIsoWeek`, `previousWeek` (пн–вс по Варшаве). Разбираем прошлую
  неделю целиком. Можно передать аргументом другую неделю: `2026-W44`.
- Итоговый файл: `analytics/<previousIsoWeek>.md`. Если уже есть (например, туда писал /screenshots) —
  обновить таблицу и разделы, не затирая колонки X Analytics, которые уже заполнены.

## 2. Данные

- `latest_report` (tf-api). Отчёт сервиса строится по понедельникам в 9:00. Если его период не покрывает
  разбираемую неделю — записать в «Нужно от Полины» («отчёт сервиса за <неделя> не построен») и считать
  по `my_posts`.
- `my_posts` (tf-db, days: 14, limit: 100) — оставить посты разбираемой недели.
- `own_stats` (tf-api, days: 7) — подписчики по дням; показы/визиты/подписки только если вносили.
- `posting_times` (tf-api, own: true, tz: "Europe/Warsaw", range: "1m").
- `own_published` (tf-api, awaiting: true) — посты студии, по которым ждут цифры X Analytics.
- `drafts/` и `edits.md` — id черновика для каждого поста.
- `experiments.md` — активный эксперимент и правило разметки вариантов.

## 3. Итоговый файл `analytics/<week>.md`

```
# Разбор недели <week> (<пн> – <вс>)

Подписчики: <на начало> → <на конец> (<+N>) — по own_stats
Постов: <n>; медиана просмотров <…>; медиана ER <…%>

## Посты недели

| Дата (Варшава) | Пост | Черновик | Вариант | Просмотры | Лайки | Ответы | Репосты | Закладки | ER | Показы | Переходы на эссе | Визиты профиля | Подписки |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Пн 26.10 14:05 | [первые слова](ссылка) | D-… / — | база | … | … | … | … | … | …% |  |  |  |  |

Посты моложе 48 часов на момент разбора — с пометкой «< 48 ч», в медианы не входят.
Колонки «Показы», «Переходы на эссе», «Визиты профиля», «Подписки» — из X Analytics, заполняет /screenshots. Переходы на эссе — главная метрика аккаунта: медиану по ним считать, как только есть 5+ постов с цифрами.

## Эксперимент: <название> — промежуточный итог
| Вариант | Постов (≥ 48 ч) | Медиана просмотров | Медиана ER |
|---|---|---|---|
Вывод: <… / «мало данных, вывода нет» если на вариант < 5 постов>
Сколько ещё нужно: <по вариантам>

## Время
<что показывает posting_times own; совпадает ли с экспериментом>

## Отчёт сервиса
<главное из latest_report: лучшие и слабые посты, выводы сервиса — коротко>

## Наблюдения для тренера
<закономерности с числами; без чисел — не писать>

## Нужны скриншоты X Analytics
- <ссылка на пост> — показы, переходы на эссе (link clicks), визиты профиля, подписки (<почему: лучший недели / вариант эксперимента / студия ждёт цифр>)
- Профиль: подписчики на <дата>

## Нужно от Полины
- … или «—»
```

## 4. Эксперимент

В `experiments.md`, в активном эксперименте, обновить строку «Промежуточные цифры» (неделя, n и медианы
по вариантам). Итог не подводить — это делает /coach.

## 5. Коммит

```
git add analytics/<week>.md experiments.md
git commit -m "analyst: разбор <week>"
```
