# /edits — правки Полины

Работает и интерактивно, и через `claude -p`. **Вопросов не задавать**: чего не хватает — в раздел
«Нужно от Полины» в `edits.md`.

## 1. Что сопоставляем

- `node scripts/now.mjs` → `last3Days`.
- Черновики: `drafts/<день>.md` за эти 3 дня. Каждый пост — id `D-…` и 2–3 варианта текста.
- Пропустить id, которые уже есть в `edits.md` (в «Парах» или «Не опубликованы» со статусом «опубликован»).
  Id из «Не опубликованы» проверять заново, пока черновику меньше 3 дней.
- Опубликованные посты: `my_posts` (days: 4, limit: 100) — с запасом на день до первого черновика.
  Для кандидатов взять полный текст через `get_post` (в `my_posts` текст обрезан до 500 знаков).

## 2. Сопоставление по тексту

Для каждого черновика и каждого опубликованного поста сравнить с каждым вариантом черновика:
- одинаковый главный герой (имя) и хотя бы 2 одинаковые конкретные цифры или даты, **или**
- совпадает большая часть первой строки (после нормализации регистра и пунктуации), **или**
- совпадает больше половины предложений.

Пост публикуется после черновика (сравнить даты). Один пост — максимум одному черновику; если
кандидатов несколько — выбрать самое сильное совпадение. Совпадение «высокое» — по двум признакам и больше,
«частичное» — по одному. Частичное записать с пометкой, чтобы Полина могла поправить.

## 3. Что изменила

По выбранному варианту черновика и опубликованному тексту — коротко, по пунктам, конкретно:
- что убрала / добавила / переставила;
- как поменяла первую строку и финал;
- длина: было → стало (в знаках);
- цифры и факты, которые поменялись;
- стиль: эмодзи, хэштеги, призыв, переносы строк.

Не пересказывай тексты целиком в пунктах — тексты и так стоят рядом.

## 4. Запись в `edits.md`

- Новые пары — в начало раздела «Пары», формат — как в шапке `edits.md`.
- Несопоставленные черновики старше суток — в «Не опубликованы»: `D-… — <тема> — не опубликован (проверено <date>)`.
  Если черновик позже сопоставился — убрать из «Не опубликованы».
- Опубликованные посты без черновика не записывать (это не правка), но посчитать их в сводке.
- Раздел «Нужно от Полины» — заменить содержимым этого прогона (например, «частичное совпадение
  D-… ↔ <ссылка>, проверь», упавший MCP) или «—».

## 5. Коммит

```
git add edits.md
git commit -m "edits: пары за <первый день>…<date>"
```

Если ничего не изменилось — не коммитить. Сводка: сколько пар, сколько не опубликовано, сколько постов без черновика.
