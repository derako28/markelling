# Алгоритм ленты «For You» — разбор открытого кода (октябрь 2026)

Источник: https://github.com/xai-org/x-algorithm, коммит `6258a15` от 2026-10-24.
По README значения по умолчанию в коде синхронизируются с основными продакшен-значениями,
но часть пользователей всегда в экспериментах — цифры ниже могут не совпадать с тем, что видит конкретный читатель.

**Статус всего файла: гипотезы.** Это выводы из кода, а не из наших постов. Правилом в `playbook.md`
любой пункт становится только с числом постов и цифрами (правило 6 из CLAUDE.md).

## Как собирается лента

1. **Кандидаты:** посты тех, на кого читатель подписан (`thunder/`), и чужие посты — поиск Phoenix
   по истории действий читателя, SimClusters, общий список популярного.
2. **Фильтры до оценки** (`home-mixer/filters/`): посты старше 48 часов, уже показанные, от заблокированных
   и замьюченных, по мьюту слов. Ответы и репосты от аккаунтов, на которые читатель не подписан, отсекаются
   целиком (`OONRetweetReplyFilter`).
3. **Оценка:** Phoenix предсказывает вероятность каждого действия этого читателя;
   `score = Σ вес × P(действие)` (`xai-value-model/scoring.rs`).
4. **Поправки** (`vm-ranker/params.rs`):
   - посты от тех, на кого читатель не подписан, ×0.75 (`rust_home_mixer_oon_weight_factor`);
     ответы и репосты от тех, на кого подписан, — тоже ×0.75;
   - повтор автора в одной выдаче: 2-й пост ×0.625, 3-й ×0.44, пол 0.25 (decay 0.5, floor 0.25);
   - буст новых авторов (см. ниже);
   - финальная перестановка ради разнообразия (DPP по эмбеддингам).
5. **Видимость** (`visibility-filtering/`): по меткам пост показывают, показывают с пометкой, прячут
   за интерстишиалом или убирают.

## Веса (`home-mixer/params/param.rs`)

| Действие | Вес |
|---|---|
| копирование ссылки на пост | 20 |
| ответ | 5 (оригинальный пост взаимного подписчика: +15, итого 20) |
| цитата | 5 |
| отправка в личку | 5 |
| подписка на автора | 4 |
| «поделиться» | 2 |
| репост | 1 |
| лайк | 0.66 (в vm-ranker 0.5) |
| время после раскрытия поста (`cont_click_dwell_time`) | 0.4 |
| клик по посту | 0.3 |
| переход по внешней ссылке (`open_link`) | 0.2 |
| дочитывание (`dwell`) | 0.05 |
| клик по профилю | 0 |
| «не интересно» / мьют / блок / жалоба | −52 / −59 / −31 / −234 |
| «пролистал, не задержался» | −0.02 |

Вес умножает предсказанную *вероятность* действия, а не число действий. Высокий вес у редких действий
(жалоба, копирование ссылки) нужен, чтобы они вообще влияли на итог; сравнивать веса как «N лайков = 1 X»
нельзя. Закладок в формуле нет.

## Буст новых авторов (`home-mixer/scorers/author_cold_start.rs`)

Условия: оригинальный пост (не ответ, не репост), у автора ≤ 50 000 подписчиков, посту ≤ 2 часов,
< 200 показов в ленте. На один запрос ленты поднимается один такой пост — на 15–16 место.
Выбор — Thompson sampling по лайкам / показам в ленте с априорным Beta(0.75, 49.25), то есть ожидание ≈ 1.5%.

## Метки AI-текста

- Каждый новый пост проходит «banger screen» (Gemma, `grox/flows/upa/`), который среди прочего выставляет
  `slop_score` и `isHighQuality`. Промпт не опубликован.
- `abuse-enforcement-service/service-lib/rules/enforcement_user.yaml`: `llm_slop_user` → метка
  `SpamHighRecall` на аккаунт на 7 дней. В `visibility-filtering/rules/levels.rs`
  (`TIMELINE_HOME_RECOMMENDATIONS`) эта метка убирает **все посты автора из рекомендаций неподписчикам**.
- `enforcement_post.yaml`: `llm_slop_post` → `RiskyHighVizReply` на пост на 30 дней.
- Аккаунты с большим числом подписчиков или высоким user-cred (PageRank, `user-cred-v2/`) проверку
  пропускают; реальные пороги в коде заменены фиктивными.
- Свои метки видно в Under the Hood: https://x.com/i/jf/under_the_hood
